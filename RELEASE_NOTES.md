# QFXMinimapTools 1.0.71

- Render the native settings window with the shared QFXWidgets factory when QFX Addon Manager is available, matching QFXUnitframes. Keep the original interface when the factory is unavailable.
- Add consistent window branding, navigation, scrollable settings pages and contact buttons. Preserve the native settings entry, refresh dependent controls, block changes during combat and release old refresh callbacks after language changes.
- Include WoW Forever 1.60.1 (Interface 16001) support and Camelot minimap fixes. On Forever, disable unsupported flight-center and shard-ID features; keep Q-button right-click and `/qfmt` / `/qmini` settings access.
- Add border visibility/size and map component anchor, edge layer, direction, size, spacing, line weight and color controls.
- Improve the calendar, mail, crafting-order and tracking icons; keep them independent of the time-text toggle. Fix Forever difficulty text and button-bag auto-close behavior.
- Remove unused TGA copies and the redundant Lua bootstrap. Archive obsolete packages, test copies and development records outside the active project; retain all required media and the icon license.
- Retain Retail 12.1.5 support and existing saved settings.
